 # 简答作业

 ## 1.
 ```
 [kernel] PageFault in application, bad addr = 0x0, bad instruction = 0x804003a4, kernel killed it.
 [kernel] IllegalInstruction in application, kernel killed it.
 [kernel] IllegalInstruction in application, kernel killed it.
 ```
 访问s态寄存器会提示PageFault，使用S态指令会提示IllegalInstruction。
 RustSBI version 0.3.0-alpha.2, adapting to RISC-V SBI v1.0.0
 ## 2.

 1.  - 刚进入时sp指向内核栈栈顶。
     - 从异常或中断处理返回，系统调用返回。
 2.  - sstatus：这是一个状态寄存器，保存了系统的状态信息，如中断使能位、当前特权级等。
     - sepc：保存了异常或系统调用发生时的程序计数器的值，即用户程序被中断的下一条指令地址。
     - sscratch：sscratch 寄存器用于在异常处理时快速交换栈指针。
 3.  - x2寄存器就是sp寄存器，已经独立处理了。
     - x4寄存器应用不会使用他，不需要保存
 4.  - sp 的值：sp变为用户栈指针，此时程序将使用用户栈进行后续操作。
     - sscratch 的值：sscratch变为内核栈指针，用于后续可能再次进入S态时的栈指针交换。
 5.  - sret
     - sret会把S特权级修改为U，恢复sstatus并把sepc恢复给pc寄存器，继续用户态的任务。
 6.  - sp的值：sp 变为内核栈指针，程序开始使用内核栈进行后续操作，如保存寄存器值、调用异常处理函数等。
     - sscratch的值：sscratch变为用户栈指针，用于在异常处理完成后恢复到用户栈。
 7.  - 触发trap后自动进入S模式
